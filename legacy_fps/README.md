# 격리된 FPS 기준선

FPS 구현은 baseline.json의 공개0.4.12rc1 커밋으로 고정합니다. 제품에 FPS 설정/모드/캐시 축소/추출 경로를 남기지 않습니다. 이 폴더는 비교와 역사 회귀 실행만 담당하고 앱에서는 import하지 않습니다.

저장소 전체 git 이력이 있는 개발 환경에서 `python legacy_fps/run_tests.py -q`를 실행합니다. runner는 git archive로 고정 커밋을 임시 폴더에 펼치고 별도 Python 프로세스에서 원래 테스트를 실행합니다. 같은 인터프리터에서 제품과 레거시 모듈을 섞지 않습니다. 해당 커밋이 없으면 전체이력fetch 후 다시 실행해야 합니다. 설치본/소스평가ZIP에 이 runner를 포함하지 않습니다.

reference/는 M2 보완 전 테스트와 v3 JSON 구현의 읽기 전용 텍스트 참고본입니다. Python 모듈로 실행하거나 제품에서 불러오지 않습니다. test-migration.json은 현재 제품으로 옮긴 공통 안전성 테스트와 M3에서 새 JSON에 맞춰 옮길 케이스를 구분합니다. 기준선 회귀 통과가 현재 제품의 JSON 검증을 뜻하지는 않습니다.
