# README 화면 관리

## 현재 화면

`images/app-review.png`는 0.4.9rc2의 실제 Qt GUI를 Linux offscreen 환경에서 실행해 캡처한 PNG입니다. 공개 가능한 자체 제작 슬라이드 세 장을 영상으로 만든 뒤 실제 분석을 실행했습니다. 앱 화면이나 버튼을 합성한 목업이 아닙니다. macOS 네이티브 화면이라고 표시하지 않습니다.

## 다음에 더 보기 좋게 다듬기

1. 직접 만든 데모 영상으로 분석을 마친 Mac 앱을 캡처합니다. 세 페이지 정도가 보이고 영상 프레임이 선명한 상태가 좋습니다.
2. 이름·개인 경로·강의 교안이 보이지 않는지 확인합니다.
3. 창 영역만 캡처해 가로 1400~1800px PNG로 `docs/images/app-review.png`를 교체합니다. 작은 글씨가 뭉개지지 않도록 과도하게 압축하지 않습니다.
4. README의 화면 설명도 캡처한 OS에 맞춰 바꿉니다.
5. 필요하면 `open-analyze-save.gif` 또는 WebP 데모를 추가합니다. Open → Analyze → 페이지 변경 → Save PDF를 8~12초로 보여주면 충분합니다.

GitHub README에는 상대 경로로 이미지를 넣습니다:

```markdown
![Slide Extractor 페이지 편집 화면](docs/images/app-review.png)
```

권장 구성: 한 문장 소개 → 실제 화면 한 장 → OS별 다운로드 → 4단계 사용법 → 특징 → 접을 수 있는 개발 문서. 배지는 버전·지원 OS·CI 정도로 유지합니다. 배너가 필요하면 단색 배경에 앱 이름과 작은 아이콘을 쓰고 실제 화면과 경쟁하지 않게 합니다. 실제로 없는 기능·성능 숫자·승인 상태를 배지에 넣지 않습니다.
