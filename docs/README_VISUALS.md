# README 화면 관리

## 현재 공개 화면

직접 제작한 발표 영상을 실제 Mac 앱에서 처리한 화면을 사용합니다. 앱 UI를 합성한 목업이 아닙니다.

| 파일 | 용도 |
|---|---|
| `images/review.webp` | README 대표 분석·페이지 편집 화면 |
| `images/auto-roi.webp` | 영상 열기와 자동 ROI 확인 |
| `images/manual-roi.webp` | 수동 ROI 조절 |
| `images/ignore-mask.webp` | 변화 감지 제외 영역 지정 |
| `images/merge-delete.webp` | 여러 페이지 선택·병합·삭제 |

README에는 대표 화면 한 장을 넣고, 단계별 이미지는 [사용법](USAGE.md)에 둡니다. 원본 캡처 해상도를 유지한 WebP이며 OS에 따라 창·버튼 모양이 다를 수 있습니다.

`images/app-review.png`는 이전 Linux 합성 슬라이드 데모 캡처입니다. 현재 대표 화면으로 사용하지 않습니다. 번호로 된 원본 PNG와 영상 파일은 공개 커밋에 추가하지 않았습니다.

## 화면 교체 시 확인

- 게시 권한이 있는 자체 제작 자료를 사용합니다.
- 개인 경로·이름·타인의 강의 자료가 의도치 않게 보이지 않는지 확인합니다.
- 실제 앱 버전과 버튼·동작 설명이 일치해야 합니다.
- 상대 경로와 파일 크기를 확인하고, 실제로 없는 기능이나 검증되지 않은 성능 수치를 표시하지 않습니다.
