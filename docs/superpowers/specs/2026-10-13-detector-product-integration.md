## Result behavior
New analyses create chronological slide groups from adjacent spatial changes. Any observed substantial transition can create a boundary, including a single-observation slide; no future persistence requirement. Same-slide annotation states update one representative. Representative ranking retains supported dark marks, penalizes one-observation marks, and avoids adjacent filled regions hiding recurrent printed edges. Return occurrences remain chronological groups, with no identity merge. Existing sample IDs, original PTS, region/mask transforms, page editing and export image caches remain authoritative.

Frozen research parameters: >20 gray delta;6% changed valid pixels AND30% nonoverlapping20px cells with≥2% changed pixels. Cells with any valid pixel use that valid population exactly as in research. Representatives: per-pixel brightest reference; support≥min(2,group size); edges >25 horizontal/vertical gradient supported in≥ceil(.6*group size); overlay cells ≥25%new darkness and≥8missing supported edges; count cells adjacent to another overlay cell; minimum occlusion count first, then supported dark pixels minus.25unsupported pixels, latest observation on exact ties. All parameters/version are explicit persisted algorithm settings, not mislabeled old MAD thresholds. These are initial validated settings, not a semantic classifier guarantee. Sensitivity changes may only be exposed after their behavior is separately validated; no reinterpretation of existing UI settings.

## Memory and lifetime
Consume prepared gray observations once, detecting adjacent boundaries online with two frame buffers. Stage gray frames as a temporary disk-backed array, not a list/stack of a whole lecture. Recording sample metadata and index intervals is allowed. At EOF, rank each group in three linear scans using fixed-size per-pixel accumulators and one frame buffer: reference max; mark-support and core-edge counts; candidate score/occlusion. Counts use sufficiently wide integers for long groups. No N×height×width Boolean allocation or copied full memmap slice. Scratch size is N*height*width uint8 bytes plus metadata; check write/open errors and report a typed analysis failure. Temporary files and mmap handles close on success/error/cancel, including Windows close-before-delete semantics. Explicit try/finally releases buffers without relying on GC. Representative selection uses original cache sample, never synthesized imagery.
